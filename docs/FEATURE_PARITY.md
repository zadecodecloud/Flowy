The unsafe upstream Face ID implementation must be removed, not represented as authentication.

Fork also disables upstream feed and automatic updater; preference mutation for screenshots and stop-by-name for recordings are disabled, but those features are incomplete. Notch geometry, hover behavior, tray safety and other required changes remain outstanding.

Follow-up: default interaction is hover with 200 ms dwell and 400 ms collapse delay in source. Collapse delay is not yet configurable and actual pointer behavior remains unverified. HUD, screenshot and recording monitoring now default off. Latest full test runs each had one timeout; focused reruns passed.

Liquid Glass is selectable in General → Notch, using public AppKit glass and behind-window material with an opaque fallback when Reduce Transparency is reported. Compact notch and Dynamic Island backgrounds are solid black with no material or stroke. Only expanded presentations use the saved surface style. Liquid Glass keeps the upper half black, and the transparency setting affects only the lower half. General → Notch shows a live appearance sample above the native style picker and transparency slider. The saved setting, reset, fallback decision and UI selection have automated coverage. Actual rendering on notched/non-notched displays, visual equivalence to the video, readability over varied backgrounds and performance remain UNVERIFIED. The About screen no longer displays source/license links, but GPL and third-party notices are retained in the project.

Lock-screen media remains a Pro feature; no production license issuer is configured. It presents three explicit states: compact player, centered expanded artwork (the default on artwork tap), and optional synchronized LRCLIB lyrics. The Lyrics button toggles artwork/lyrics; the top-right × returns either expanded state to compact. Transient presentation state resets on release and is no longer persisted into the next lock session. Expanded controls include remaining-time scrubbing, shuffle/repeat, supported source volume, favorite menu and audio output selection. The foreground window uses compact media bounds when collapsed and fills the display in either expanded mode; the separate artwork background passes mouse events through. Both windows explicitly permit visibility without login and are ordered by AppKit before being adopted into the private space. SkyLight mutators use void signatures and space IDs are 64-bit; leftover return-register values must never be interpreted as CGError. WindowServer membership is queried using mask 0xF, which includes OS/private spaces. An opt-in native integration test confirms actual membership with a fully transparent, mouse-transparent, non-key panel. The private space is re-shown and windows are reattached in bounded retries on lock/wake. Lock state is reconciled against the session dictionary to recover missed notifications. Playback metadata/artwork is retained for at most five seconds when the session disappears during lock. Lyrics support synchronized seekable lines, plain text, unavailable/error states and bounded network retries. Focused unit/integration tests cover these states, media commands, geometry and page navigation. Native preview controls and the three-state cycle (including closing/reopening from both expanded modes) were manually exercised with fixture media. The opt-in live LRCLIB smoke test fetched 20 synchronized lines for a public test track. The user has confirmed the compact media panel appears on the real lock screen after the SkyLight fix. Sleep/wake and individual controls against a live Spotify session still need further on-device acceptance testing. The expanded lyrics presentation now fills the display with an adaptive album/control column, a large lyrics column and an album-colored moving mesh; Reduced Motion and the static-background setting stop the mesh timeline. Both expanded modes cover the entire display. Close returns to the compact panel. A display-idle assertion can keep the Mac awake for the lifetime of a visible player on the locked screen. The Xcode UI runner on this Mac times out enabling automation; unit tests can run through the XCTest CLI in an isolated app bundle. Private SkyLight functions are unsupported and may change between macOS releases.

Rightward horizontal gestures over compact media open File Tray, including an empty drop zone. Leftward gestures return to the active player; without a media session they close an empty tray. In expanded mode horizontal page gestures are recognized across the entire notch. One gesture produces at most one page change; claimed horizontal momentum is consumed, while vertical scrolling and direct slider dragging remain available. The context menu provides the same actions. A selected page only overrides the relative ordering of media and tray, preserving critical/temporary activity preemption. File Tray remains Pro-gated.


The clear-glass appearance uses the public macOS 26 material APIs: a lightly diffused desktop backdrop for the notch and native interactive clear glass for controls. Settings cards/search, lock-screen controls and File Tray items share the optical treatment. A single document diffusion plane and contrast wash preserve Settings text readability. The initial clear-glass migration runs once, adopts glass for notch/lock widgets and preserves transparency values above 78%; later user changes persist. Reduced Transparency supplies solid surfaces and Reduced Motion disables press scaling and player feedback motion. The `NotchFlow Glass Preview` Debug scheme opens ordinary Settings and media preview windows for review without locking the computer.

## Media v2 — 2026-11-04

Applied the approved v2 design: existing notch and compact card retain their artwork, typography and layout; shared media controls use balanced 38 pt compact and 40 pt expanded targets. Playback glyphs are 22/24 pt and skip glyphs are 16/19 pt. Clear native glass responds to hover/press and selected state without the old rotation/pulse feedback. Nearby control lenses share a GlassEffectContainer; inactive hover lenses use the identity material. Reduced Motion and Reduced Transparency remain supported.

Artwork mode has a centered cover, persistent transport/volume footer and metadata at the lower left on wide displays; narrow displays stack the footer. Lyrics mode places artwork and controls beside the lyric column. The Lyrics and close controls stay in the same top-right positions in both modes, with 44 pt hit regions. The album-colored backdrop uses the same contrast wash in both modes. App/menu logo redesign remains deferred.

Validation: the focused suite covers layout across six viewport sizes, stable close/Lyrics targets, cover/footer separation, mode transitions, full-display backdrop coverage, lyrics state/seek, playback state and whole-notch swipes. Native preview interactions were exercised with fixture media: compact → artwork → lyrics, previous track, play/pause, shuffle, repeat, volume and seeking by lyric line. Screenshots in ../NotchFlow-Media-v2 are labeled as native preview or XCTest rendering. Final grouped-material rendering is also checked through XCTest snapshots. This update has not been re-tested on the real locked screen or against live Spotify controls.
