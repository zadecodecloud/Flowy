# Changelog

## 1.0 — first release

- Music in the notch: artwork, scrubbing, favorites, output device, optional volume slider, and an Explicit or Lossless badge.
- Volume and brightness HUD in the notch, replacing the macOS overlay.
- File Tray with AirDrop from the notch (Pro).
- Music player with lyrics on the lock screen (Pro).
- AirPods and accessory battery, charging, Focus, hotspot, VPN, downloads, calendar and timers.
- Every permission is explained with a preview before macOS asks.
- Flowy Pro: one-time purchase, lifetime updates, 2 Macs per key, 14-day trial.
- Automatic updates with Sparkle.
